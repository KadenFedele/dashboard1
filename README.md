# Kaden's Personal Dashboard

A personal dashboard with a weather widget and a dark mode toggle. The weather
loads from a JSON file, and the dashboard remembers which theme you picked.

## Features

- Weather widget that shows the temperature, location, and conditions
- Dark mode toggle in the header
- Saves your theme choice, so it is still there when you come back
- Readable in both light and dark mode
- Works on phones and desktops

## Technologies Used

- HTML
- CSS (custom properties for the theming)
- JavaScript (fetch, localStorage)
- GitHub Pages
